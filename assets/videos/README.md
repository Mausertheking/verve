# /assets/videos

Bundled videos, one per lesson and drill per language:

```
lessons/<lesson-id>.<az|ru|en>.mp4
drills/<drill-id>.<az|ru|en>.mp4
```

Nothing is streamed or fetched. `src/content/videos.ts` is generated by
`node explainers/build.mjs` from whatever files exist here — Metro bundles only
files it sees in a static `require`. A missing language falls back to `az`.

**Current files are rendered explainers** (960×540, 24 fps, no audio), built
from the content text by `explainers/`. Re-render after editing content:

```bash
node explainers/build.mjs
```

**Filmed footage** replaces an explainer by using the same filename. Raw
camera files stay out of git (see `.gitignore`); only the final, compressed
clip goes in these folders.
